# rover marino ficticio

Este es un script interactivo desarrollado en Python que simula el sistema de análisis de un rover submarino no tripulado encargado de explorar fosas oceánicas. 

## Características
* Captura de datos físicos (Temperatura y Salinidad) y biológicos (Bioluminiscencia).
* Clasificación automática de entornos (Zona Abisal Estándar, Resurgencia Termal, Zona Glacial Extrema).
* Sistema optimizado de alertas críticas en consola mediante caracteres de escape.

## Conceptos Aplicados
* Manejo y conversión de tipos de datos (`float`, `input`).
* Estructuras de control de flujo condicional (`if-elif-else`).
* Operadores lógicos compuestos (`and`).
* Optimización de cadenas de texto y saltos de línea (`\n`).
